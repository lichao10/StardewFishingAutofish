# 星露谷自动钓鱼（Stardew Fishing Autofish）

[English](README.md) | **简体中文**

<img src="common/src/main/resources/assets/stardew_fishing_autofish/icon.png" width="128" alt="星露谷自动钓鱼图标" />

为 **Stardew Fishing** 提供客户端自动钓鱼功能，自动完成抛竿、咬钩收竿和钓鱼小游戏，并优先尝试获取宝箱。

[前往 CurseForge 下载](https://www.curseforge.com/minecraft/mc-mods/stardewfishingautofish)

## 功能

- 自动抛竿、咬钩收竿，并控制小游戏中的绿色钓鱼条。
- 出现宝箱时优先积满宝箱进度，同时尽量保持鱼不脱钩，随后完成钓鱼。
- 每次钓鱼结束后自动继续。
- 默认使用 **F8** 开关，支持自定义快捷键。
- 支持后台钓鱼，并在鱼竿耐久即将耗尽时停止。

## 使用方法

1. 手持鱼竿，面向可钓鱼的水面，按 **F8** 开始，再按一次停止。
2. 切换窗口或最小化前，请关闭背包、聊天框和暂停菜单。关闭自动钓鱼后，会恢复原来的失焦暂停设置。

高难度鱼类仍可能逃脱。
