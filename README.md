# Stardew Fishing Autofish

**English** | [简体中文](README.zh-CN.md)

<img src="common/src/main/resources/assets/stardew_fishing_autofish/icon.png" width="128" alt="Stardew Fishing Autofish icon" />

A client-side addon for **Stardew Fishing** that automates casting, bite detection and the fishing minigame, with treasure prioritization.

[Download on CurseForge](https://www.curseforge.com/minecraft/mc-mods/stardewfishingautofish)

## Features

- Automatically casts, reels in on a bite and controls the green fishing bar.
- Prioritizes treasure chests while trying to keep the fish hooked, then finishes catching the fish.
- Continues fishing automatically after each catch.
- Toggles with **F8**, with a configurable key binding.
- Supports background fishing and stops when the fishing rod is nearly broken.

## How to use

1. Hold a fishing rod, face fishable water and press **F8** to start. Press it again to stop.
2. Close inventory, chat and pause menus before switching windows or minimizing the game. Disabling automation restores the previous pause-on-lost-focus setting.

Difficult fish can still escape.
